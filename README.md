# 🎬 Movie Recommendation System

A **beginner-friendly end-to-end Movie Recommendation System** built using **Python** and **Flask**.  
Users can type a movie name in the frontend and get the **top 5 similar movie recommendations** using **content-based filtering**.

---

## 🧩 Overview

- **Backend:** Python (machine learning logic)
- **API:** Flask (connects backend to frontend)
- **Frontend:** HTML + JavaScript
- **Dataset:** MovieLens latest small dataset (`movies.csv`)

This project demonstrates a full-stack ML application: backend logic, API, and a user-friendly frontend.

---

## 🛠️ Features

- Search for any movie from the dataset  
- Get **top 5 similar movie recommendations**  
- Content-based filtering using **TF-IDF** and **cosine similarity**  
- Interactive frontend using HTML and JavaScript
